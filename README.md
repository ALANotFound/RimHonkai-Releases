## 下载 / Download

请前往 [Releases](https://github.com/ALANotFound/RimHonkai-Releases/releases) 下载最新版本：

1. 下载 `RimHonkai_<版本>.zip`
2. 解压得到 `RimHonkai/` 文件夹
3. 将整个 `RimHonkai/` 文件夹放入 RimWorld 的 `Mods/` 目录
4. **必须**订阅 [Harmony](steam://url/CommunityFilePage/2009463077)
5. 游戏内启用本 Mod，加载顺序置于 Harmony 之后
